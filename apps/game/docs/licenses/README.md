# License-text archive

Keep copies of the license texts for third-party assets used here.

**Save all three original copies in Lesson 1.** Do not delay license records
no matter which lesson introduces an asset. If you leave them for later, you
have to reconstruct which file used which license when you build the credits
screen.

The last column in the table below is the **lesson that first copies the
licensed asset into the project**, not the moment the text copy is saved.

| File | Target | Asset-introduction lesson |
| --- | --- | --- |
| `OFL-1.1.txt` | Galmuri11 | Lesson 1 (title-screen type) |
| `NOTO-OFL-1.1.txt` | Noto Sans CJK SC | Release internationalization (CJK fallback) |
| `CC0-1.0.txt` | Ninja Adventure, Kenney packs | Lesson 1 (title background, beacon, music, SFX) |
| `GODOT-MIT.txt` | Godot Engine | Lesson 1 (the engine itself) |

Godot's engine license appears on screen in the Lesson 15 credits screen, but
the original text copy is still saved in Lesson 1.

The Android APK shows credits on the Lesson 15 credits screen, and the same
credits go in the itch.io page description.

See `apps/docs/docs/assets/third-party.md` for the summary.
