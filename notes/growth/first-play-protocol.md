# Course first-play sessions — moderator protocol

Prepared 2026-10-13. Manual recruitment and observation for up to five
volunteer course readers who have never played. Preparation only: no
sessions arranged, no participants counted, no clock started.

## Rules

- Contact runs through the existing public support email only. The
  invitation page offers a draft; it sends and registers nothing.
- An enquiry is not consent. Arrange each session separately and record
  explicit consent before any observation. The participant can stop at any
  time, with notes kept only up to the stop point.
- No automatic screen recording. Quote a participant only with permission.
- Never request purchase, review, account, player ID, password, receipt,
  or screenshots.
- Contact PII (names, email addresses) stays in the mail thread. It never
  enters Git, notes, or state files. Notes use anonymous codes P01–P05.
- Keep three separations: contacted vs scheduled vs completed; self-report
  vs directly observed; store attribution rows vs session outcomes. A store
  click is channel evidence, never session evidence. Neither a store click
  nor moderator QA counts as a volunteer completion.
- The participant installs before the session but first opens with the
  moderator. The observation clock starts at that agreed first open.
- Record anything unobserved as unknown. Never infer a time, a death, or a
  quit point that was not seen.
- No rewards, ads, or spend. Budget stays 0 KRW.

## Session shape (~20 minutes)

1. Confirm consent, code, and stop-anytime on the record.
2. First open together: record device model, OS version, and the app
   version on the title screen. Start the observation clock.
3. Observe the opening minutes, anchored to the clock:
   - time from first open to actual run start (title/tap-through separate
     from play);
   - first beacon reached (yes/no + time from run start);
   - deaths inside the run's first 60 seconds (time spent signing in or
     onboarding does not count);
   - the quit screen/step.
4. Ask short questions; mark every answer self-report unless directly seen.
