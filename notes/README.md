# Materials for the people making the course

Documents here **do not go on the docs site.** Only the people making the
lessons read them. Students see `apps/docs/` only.

| Folder | Contents |
| --- | --- |
| `plans/` | Goals, changes, and done conditions for each lesson |
| `scripts/` | Recording scripts (screen / narration / watch-outs, three columns) |
| `workflow/` | Recording pipeline and implementation AI prompts |
| `release/` | Pre-release QA and build checklists |
| `art/` | Custom-asset art bible, production specs, review criteria |

## Why they are separate

The docs site is for students. If Lesson 1 plans, recording scripts, and the
recording pipeline lived there too, it would be unclear what to read. So the
site holds **lessons** and **reference** only, and production documents stay
here in the repository.

## File-name rule

Lesson numbers use `chapter-01`, `chapter-02`, and so on.
Follow the concept order of the official Godot intro course, but count
lessons from 1.
